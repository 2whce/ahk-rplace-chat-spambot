# autohotkey rplace.live chat spambot
an easy-to-use autohotkey-based program that allows you to spam on the rplace.live chat channels easily, with no web browser scripts or extensions required, meaning that it'll be very less likely for it to be made broken or "patched" by both zekiah and blobkat.

# dependecies required
[`autohotkey`](https://autohotkey.com/): more specifically version 1.1, i have not tested this script in any way in version 2.0

# how to use
- first, visit [`rplace.live`](https://rplace.live) on any browser, type in your username and accept the username prompt (or just ignore this if you've already entered in a username before or don't want to enter any username), then open the "main.ahk" autohotkey script that contains the spambot.
- second, enter any number into the "amount of spam" number field to set the amount of spam you want to send. (only works for the "aut" method)
- third, either choose the "aut" (automatic quote spam) or "man" (manually spam messages with your keyboard and send them by pressing F1) methods.
- fourth, click on the "enter message" text field and press f1 to start spamming in chat.
- finally, if you recieve any kind of hcaptcha or cloudflare captchas on rplace.live, press f4 to pause the autohotkey script, as the site's captchas don't allow you to send any kind of chat messages whatsoever. once you've solved the captcha successfully, press f4 again to continue your spamming session peacefully
- just have fun spamming on rplace.live chat!

# script keyboard controls
**F1**: starts spamming on the rplace chat.

**F2**: lists all of variables in the script. this was added in solely for easy debugging and testing.

**F3**: reloads the spambot script.

**F4**: pauses the rplace chat spambot script in case you want to stop spamming, or any hcaptcha or cloudflare captcha appears on the rplace website and you want to solve it before continuing just to continue spamming, since chat messages do not get sent into rplace.live if the website's captchas are left unsolved.
